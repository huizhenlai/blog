# 视觉标定方法

## 基本原理

### 内参

摄像头的成像过程由内参矩阵 $K(3 \times 3)$ 决定
$$
K = \begin{bmatrix} 
f_x & 0 & c_x \\\\
0 & f_y & c_y \\\\
0 & 0 & 1 
\end{bmatrix}
$$
其中  $f_x, f_y$ 是焦距（像素单位）影响视场角， $c_x, c_y$ 是图像中心坐标。通常来说摄像头为定焦，长焦镜头近处会模糊，短焦镜头看不清远处。

### 畸变

畸变系数矩阵 $D (5 \times 1)$ ， 默认只是用五个参数：


$$
D = \begin{bmatrix} 
k_1 & k_2 & p_1 & p_2 & k_3 \\
\end{bmatrix}
$$



**径向畸变：**

- 物理原因：透镜形状导致光线在边缘的弯曲，产生“桶形畸变”或“枕形畸变”。

- 数学模型：

$$
x_{corrected}=x \cdot(1+k_1r^2+k_2r^4+k_3r^6) \\\\
y_{corrected}=y \cdot(1+k_1r^2+k_2r^4+k_3r^6)
$$

​    其中 $r=\sqrt{x^2+y^2}$ ， $(x,y)$ 是归一化坐标（相对于主点和焦距）

- 系数含义:
    * $k_1$：二阶项，主导中心区域的畸变（如桶形或枕形）。
    
    * $k_2$：四阶项，校正边缘更复杂的畸变。
    
    * $k_3$：六阶项，用于极端广角镜头的高阶修正。
    
- 符号影响：
    - $k_1 < 0$：校正桶形畸变（图像边缘向内弯曲）。
    - $k_1 > 0$：校正枕形畸变（图像边缘向外弯曲）。



 **切向畸变**

- 物理原因：透镜与成像平面不平行（安装倾斜），导致图像拉伸或压缩。

- 数学模型：

$$
x_{corrected} = x+2p_1xy + p_2(r^2+2x^2)\\\\
y_{corrected} = y+p_1(r^2+2y^2)+2p_2xy
$$

- 系数含义：

  - $p_1$ 和  $p_2$：描述切向畸变的非对称性。
  - 值越大，切向拉伸或压缩越明显。

- 方向影响：由镜头倾斜方向决定，例如：

  - $p_1 > 0$ ：沿某一方向的切向拉伸。
  - $p_2 < 0$ ：沿另一方向的切向压缩。

  

### 方法1：用已知物体测量(标定法)

如果无法获取传感器参数，可以使用**已知尺寸的物体**放置在**已知距离**来计算 $f_x, f_y$
1. 准备一个已知宽度 $W_{real}$ 的物体（例如 A4 纸，宽度 210mm × 210mm）。
2. 放置在已知距离 $F_{real}$ 远的位置（例如 1m）。
3. 拍照并测量物体在图像中的宽度 $W_{img}$（像素 px）。
4. 计算焦距 $f_x$：
   $$
   f_x = \frac{W_{img} \cdot Z_{real}}{W_{real}}
   $$
   同理，使用已知高度的物体，可以计算 $f_y$

### 方法 2：使用 OpenCV 进行相机标定

如果需要更精确的焦距，建议使用 OpenCV 进行**相机标定**，步骤如下：

1. 打印棋盘格（如 9 × 6 网格）。
2. 用摄像头拍摄多张不同角度的棋盘图片。
3. 使用 OpenCV 的 `cv2.calibrateCamera()` 计算相机内参。

棋盘格可以使用 [Camera Calibration Pattern Generator – calib.io](https://calib.io/pages/camera-calibration-pattern-generator) 校准网站的PDF用A4纸固定尺寸打印，也可以购买专业的标定板进行标定。但是需要注意的是，标定板尽可能买尺寸大一点的，否则对于长焦相机，太小的标定板会模糊导致参数不准。



## 标定

1. 拍摄棋盘格图片不同角度，数量尽可能多

```python
import cv2
import os

# 打开摄像头，0 代表默认摄像头，如果有多个摄像头，可以尝试 1, 2, 3... 对于笔记本来说通常外接摄像头为 1
cap = cv2.VideoCapture(1)  

if not cap.isOpened():
    print("无法打开摄像头")
    exit()

frame_width = 1920
frame_height = 1080
cap.set(cv2.CAP_PROP_FRAME_WIDTH, frame_width)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, frame_height)

# 获取实际分辨率
actual_width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
actual_height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
print(f"实际分辨率: {actual_width} × {actual_height}")

# 确保保存目录存在
save_dir = './calibration_images/'
if not os.path.exists(save_dir):
    os.makedirs(save_dir)

while True:
    ret, frame = cap.read()
    if not ret:
        print("摄像头无数据")
        break

    cv2.imshow('Camera', frame)
    key = cv2.waitKey(1) & 0xFF  # 处理键盘输入

    if key == ord('s'):  # 按 's' 保存图片
        files = os.listdir(save_dir)
        images = [f for f in files if f.startswith('captured_image') and f.endswith('.jpg')]

        # 获取当前最大编号
        max_index = max(
            [int(image.split('_')[2].split('.')[0]) for image in images if image.split('_')[2].split('.')[0].isdigit()],
            default=0
        )

        # 生成新的文件名
        new_filename = os.path.join(save_dir, f'captured_image_{max_index + 1}.jpg')
        cv2.imwrite(new_filename, frame)
        print(f"保存成功: {new_filename}")

    elif key == 27:  # 按 'Esc' 退出
        break

cap.release()
cv2.destroyAllWindows()
```

Opencv存在以下问题，默认的摄像头打开分辨率为 640 × 480，如果需要调整分辨率，首先是速度非常慢，其次似乎是基于640 × 480的结果进行resize，分辨率较低。（**该问题待完善**）

2. 基于拍摄的图片进行校准

```python
import cv2
import numpy as np
import glob

# 1. 设置棋盘格参数
rows, cols = 7, 10
chessboard_size = (rows, cols)  # 角点的行列数
square_size = 1.5  # 棋盘格每个方格的实际尺寸（单位：cm）

# 2. 准备 3D 物理坐标
objp = np.zeros((chessboard_size[0] * chessboard_size[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:chessboard_size[0], 0:chessboard_size[1]].T.reshape(-1, 2)
objp *= square_size  # 乘以实际尺寸，单位 mm 或 cm

# 3. 读取棋盘格图像
images = glob.glob("./calibration_images1*.jpg")  # 确保文件路径正确
obj_points = []  # 存储 3D 物理坐标
img_points = []  # 存储 2D 图像坐标
print(len(images))
sucess_count = 0
# 4. 遍历所有图像
for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    
    # 5. 角点检测
    ret, corners = cv2.findChessboardCorners(gray, chessboard_size, None)

    if ret:
        obj_points.append(objp)
        # 6. 角点亚像素优化
        corners2 = cv2.cornerSubPix(gray, corners, (rows, cols), (-1, -1),
                                    criteria=(cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001))
        img_points.append(corners2)
        sucess_count += 1
        
        # 7. 画出角点并显示
        cv2.drawChessboardCorners(img, chessboard_size, corners2, ret)
        cv2.imshow("Corners", img)
        cv2.waitKey(50)
        print(sucess_count)
    else:
        print("角点检测失败")


cv2.destroyAllWindows()

# 8. 相机标定
ret, camera_matrix, dist_coeffs, rvecs, tvecs = cv2.calibrateCamera(obj_points, img_points, gray.shape[::-1], None, None)

# 9. 输出标定结果
print("相机内参矩阵:\n", camera_matrix)
print("畸变系数:\n", dist_coeffs)

# 10. 保存标定结果
np.savez("camera_calibration.npz", camera_matrix=camera_matrix, dist_coeffs=dist_coeffs)

# 11. 进行畸变校正测试
img = cv2.imread(images[0])  # 读取一张图像进行测试
h, w = img.shape[:2]
new_camera_matrix, roi = cv2.getOptimalNewCameraMatrix(camera_matrix, dist_coeffs, (w, h), 1, (w, h))
dst = cv2.undistort(img, camera_matrix, dist_coeffs, None, new_camera_matrix)

# 12. 显示校正结果
cv2.imshow("Original", img)
cv2.imshow("Undistorted", dst)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

### 举个例子

相机内参矩阵: 
$$
K' = \begin{bmatrix}
 889.2 & 0.0 & 1056.3 \\\\
 0.0 & 889.6 & 567.6 \\\\
 0.0 & 0.0 & 1.0
\end{bmatrix}
$$
畸变系数:
$$
D' = \begin{bmatrix}
 -0.03189556 & 0.2061865 & -0.00417316 & 0.00529574 & -0.20343818
\end{bmatrix}
$$
从实际的结果上来看

1. $ f'_x = 889.2 \approx f'_y = 889.6$ ，基本认为是正方形的像素各店，在不进行直接图像拉伸的情况下，不会存在长宽比例失调的情况。

2. 测量光心 $(c'_x, c'_y) = (1056.3, 567.6)$ 与实际像素中心

   $$ (c_x, c_y) = (\dfrac{1920}{2}, \dfrac{1080}{2}) = (960, 540)$$  有一定差距，体现在画面物体会偏右下。

3. 焦距测试较稳定，光学数据和畸变系数在多次测量过程中有一定变化。



### DeepSeek给的大概范围

| 镜头类型     | 建议模型                 | 典型畸变系数范围            |
| :----------- | :----------------------- | :-------------------------- |
| **普通镜头** | 径向+切向（5参数）       | `k1: ±0.1`, `p1/p2: ±0.01`  |
| **广角镜头** | 径向+切向（5参数）       | `k1: ±0.3`, `k3: ±0.05`     |
| **鱼眼镜头** | 鱼眼模型（4参数）        | 使用 `cv2.fisheye` 专用函数 |
| **工业相机** | 径向（3参数）+ 切向（2） | `k1: ±0.05`, `p1/p2: ≈0`    |
